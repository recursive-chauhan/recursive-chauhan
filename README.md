## About

I'm Muhammad Hassan, a Computer Science student at UET Lahore. I build at the intersection of generative AI and full-stack development, shipping production-grade applications in ASP.NET and React. My work focuses on integrating LLMs into real workflows, not just demos.

I also explore cybersecurity through reverse engineering and malware analysis. Understanding how systems break is the best way to learn how to build them right. That mindset shapes everything I write.

Beyond code, I run technical workshops, mentor students, and build communities where people learn from each other. Tech is more fun when you're not doing it alone.
